# BSDSF24A038-OS-A02

Operating Systems Programming Assignment 02: extending the instructor's C `ls` utility.

Student: Ghania Malik (BSDSF24A038).

## Build on GNU/Linux

```sh
make
./bin/ls
```

The source begins with the instructor's original `lsv1.0.0.c`, renamed to
`src/ls-v1.0.0.c` to match the assignment layout. All features extend that same file.

Starter: https://github.com/arifpucit/OS-Codes/tree/b338d8ce366e729e71e3c6b630f27f9c7f14637b/Programming-Assignments/PA-02

The current upstream assignment folder contains the C file and README, but no
Makefile or src directory. This project therefore supplies the required Makefile
and directory layout, while preserving the original starter source in the initial
setup commit.

Helper examples: https://github.com/arifpucit/SP-VLecs/tree/master/arifpucit-spvl-repo/14

Watch the instructor's required "Making of ls" video and study the implementation
and report before the viva. Video viewing is a student requirement; this repository
does not claim it has been completed.
